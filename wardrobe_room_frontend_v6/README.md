# Wardrobe Room Frontend Demo v6

Open `index.html` directly in a browser.

Updates in v6:
- Wardrobe focus camera/animation is restored to the same framing as v4.
- The category/item interaction logic from v5 is preserved.
- The 4×2 item panel is shifted farther right and is allowed to overlap the wardrobe.
- Item slots are larger.
- Each item slot uses an approximate height:width ratio of 4:3.
- Clicking the wardrobe again still does not exit; clicking another room area exits.
- Wardrobe hover enlargement remains disabled while focused.
