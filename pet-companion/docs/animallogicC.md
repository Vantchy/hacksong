## 宠物内在逻辑（奖励点数版）


### 一、核心原则

1. **不打断**：所有表达通过视觉微动传递，无弹窗、无声音、无强制提醒。
2. **正向激励**：学习赚取点数，点数兑换互动。不学习不会死，点数不衰减。
3. **低负担**：允许用户有正常的生活节奏，不需要刻意打工。
4. **共场层与互动层分离**：
   - **共场层（免费）**：宠物存在、呼吸、趴着陪你——这是产品的核心价值，始终免费，无需任何条件。
   - **互动层（消耗星）**：喂食、抚摸、玩耍等主动操作——这是学习成果的奖励，消耗专注星。
   - 共场层是底线体验，互动层是增值体验，两层互不影响。


### 二、属性系统

保留饱食、快乐、精力、清洁四个经典宠物属性，但它们的维护方式发生了变化：属性不会自动下降太多，但互动需要消耗点数。

| 属性 | 含义 | 自动变化 |
|------|------|---------|
| 饱食度 | 宠物的"饱足感" | 在线每小时-2，离线每小时-1（极慢） |
| 快乐度 | 宠物的心情 | 不自动下降，只靠互动提升 |
| 精力 | 宠物的活跃程度 | 学习时跟随用户疲劳度下降；休息/离线时恢复 |
| 清洁度 | 宠物的干净程度 | 在线每小时-1，离线每小时-0.5（极慢） |
| 亲密度 | 长期陪伴的见证 | **只增不减，无硬上限**，每次互动微量增加；是总陪伴时长的累计指标 |

**关键变化**：属性自动下降速度极慢，用户即使几天不打开，宠物也不会濒死。下降的意义不在于惩罚，而在于"有维护的需求"从而让点数有价值。

**亲密度设计详解（无上限 + 里程碑）**：
- 亲密度 **不做硬上限**，理论上可以无限增长。
- 用户**看不到亲密度数字**，避免产生"快满了"的焦虑或"满了没意思"的空虚感。
- 取而代之的是 **里程碑节点**：亲密度达到特定区间时，宠物的行为会发生微妙变化。
- 里程碑节点**逐渐稀疏**：前期隔几天就有新变化，后期间隔几周甚至几个月，确保长期都有盼头。
- 里程碑解锁的是 **"陪伴质感"的提升**（新姿势、新表情、新互动方式），而非功能按钮。
- 里程碑**不回溯**，到了就不会丢，强化"长期陪伴的见证"这个定位。

#### 亲密度里程碑示例

| 亲密度区间 | 宠物行为变化 |
|-----------|-------------|
| 0-100（新手期） | 正常待机，偶尔看你一眼 |
| 100-300（熟悉期） | 会主动往你鼠标/光标方向挪一点 |
| 300-600（亲密期） | 你专注时它会换更舒服的姿势趴下，而不是一直端坐 |
| 600-1000（挚友期） | 你走神回来，它会做一个"等你很久了"的伸懒腰动作 |
| 1000+（forever） | 解锁老用户专属的细微表情，比如在你习惯的学习时段提前调整好姿势等你 |

> **给 A/B 的对接说明**：C 在 `GameLogic` 中提供了 `getAffectionStage(state)` 方法，返回当前亲密度所处阶段标识（`'newbie'` / `'familiar'` / `'intimate'` / `'bestie'` / `'forever'`），B 可直接调用并根据返回值切换宠物 CSS class，A 需要为每个阶段设计对应的视觉形态和动画。详见 `samename.md` 中的方法签名。


### 三、点数系统（新增核心）

引入一种名为"专注星"（暂定）的奖励点数，作为学习投入与宠物互动之间的兑换媒介。

#### 赚取方式

- **连续专注学习**：每完成一个连续的专注时段，获得专注星。**前 15 分钟获取速率加倍**（每5分钟2星），之后稳定到正常速率（每5分钟1星）——帮助用户跨过"启动最难"的门槛。
- **每日首次写下意图**：打开页面后，写一句话告诉宠物今天想做什么（如"好烦，不想学""今天想搞定论文第一章"），获得小额奖励。这一步本身就是 README 模块2"状态镜像"的入口。
- **完成自定学习目标**：小额额外奖励。

#### 扣除方式

- **主动重置宠物状态**：一次性扣除较多点数。
- **无离线衰减**：专注星只赚不扣。用户离线的唯一代价就是"没赚到新星"，已有的星不会减少。

#### 点数上限

设置软上限，超出部分不累计（防止刷分后永远花不完）。

**设计意图**：点数是对"用户投入学习"的量化确认，是"努力过的凭证"，而非生存必需品。


### 四、互动系统（点数驱动 + 每日免费）

互动分为两类：**每日免费互动**（维持陪伴底线）和 **点数互动**（消耗专注星，获得更多反馈）。

#### 每日免费互动（每天各限 1 次）

| 动作 | 消耗 | 属性变化 | 说明 |
|------|------|---------|------|
| 抚摸 | 免费 | 亲密度+1，快乐度+2 | 最简单的回应，哪怕没学习也能摸摸它 |
| 打招呼 | 免费 | 快乐度+1 | 宠物会抬头看你一眼，轻轻回应 |

> 免费互动保证：用户即使今天没学习，打开页面依然能和宠物有简单的接触，维持"共场陪伴"的底线体验。

#### 点数互动（消耗专注星）

| 动作 | 消耗专注星 | 属性变化 | 说明 |
|------|----------|---------|------|
| 喂食 | 3 | 饱食度+15 | 解决饥饿 |
| 洗澡 | 3 | 清洁度+20 | 保持干净 |
| 击掌 | 2 | 干劲+5，快乐度+3 | 完成任务的仪式感 |
| 加油 | 1 | 快乐度+5 | 随机鼓励语，快速正反馈 |
| 抚摸（额外） | 1 | 亲密度+2，快乐度+3 | 超过免费次数后的额外抚摸 |
| 睡觉（快速充电） | 2 | 精力+20 | 宠物恢复活跃 |

**关键原则**：消耗点数的行为都是"我想奖励一下自己/宠物"时主动触发的，不是被系统逼着做的。点数够就多互动，点数不够就安心学习去赚。


### 五、学习—点数—互动的关系链

这是整套逻辑的核心闭环：

> **用户专注学习 → 赚取专注星 → 用专注星跟宠物互动 → 宠物状态变好 → 用户获得情绪正反馈 → 更愿意继续学习**

四个环节全部是正向循环：
- 学习产生点数（而非产生负罪感）
- 点数兑换互动（而非靠意志力硬扛）
- 互动带来陪伴感（而非被消耗精力）
- 陪伴感反哺学习动力（而非分散注意力）

**反向设计（不学习时）** ：
- 不学习 → 不赚点数 → 逐渐消耗现有库存 → 点数变少 → 互动受限
- 但属性不会崩盘，宠物不会消失 → 用户不会因为压力而弃用


### 六、经济平衡原则

- **获取速率**：1小时专注约可获得15-20专注星（前15分钟速率加倍，之后稳定）
- **免费额度**：每天2次免费互动，0成本维持陪伴
- **消耗速率**：一次完整点数互动（喂食+抚摸+加油）约需5-7专注星
- **离线衰减**：无。离线不扣星，用户安心休息
- **结论**：正常学习30分钟就能覆盖当天的点数互动需求。偶尔休息一天，免费互动依然够用，宠物不会冷落你。


### 七、成长系统

- **经验来源**：消耗专注星进行互动时，同步获得经验值。
- **升级依据**：专注于"与宠物互动的总次数/总消耗"，而非单纯的学习时长——因为互动是你"用学习成果兑换来的"，比单纯计时更能体现投入。
- **升级效果**：外观逐渐丰富；解锁少量新互动动作；每日首次写下意图的奖励略微增加。
- **退化机制**：无。只进不退。


### 八、提醒机制

全部通过视觉微动传递，不弹窗、不出声。与点数相关的表达克制且低调：

- 点数充足时：宠物姿态活泼，出现频率略高
- 点数偏低时：宠物姿态平稳，不催促
- 接近专注上限：舒展/变换姿态
- 深夜学习：闭眼/垂首打盹态
- 走神/返回：注视/轻微欢迎动作

以上均不弹文字、不出声音。


### 九、数据画像

保持不变：

- **记录维度**：专注时长、中断次数、日总时长、连续最长记录、情绪标签
- **画像输出**：通过宠物行为（准时出现、适时鼓励）表达理解，不弹数据报告
- **更新频率**：每次学习后即时更新，每日重算统计结论


### 十、一句话总结

> **学习赚星星，星星换陪伴。不学不会死，不学也能摸摸它。** 宠物不惩罚你，不冷落你。你努力了，它会更活跃地回应你；你累了，它依然安静地趴在那里陪你——所有互动都来自你付出过的专注，而不是凭空点出来的。
