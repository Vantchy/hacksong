# 🐾 宠物伙伴 — 共享需求文档

## 项目概述
一个基于浏览器的虚拟宠物养成游戏，通过交互按钮和倒计时机制模拟宠物成长。

## 项目结构

```
pet-companion/
├── index.html          # 主页面（HTML骨架 + 静态资源引用）
├── css/
│   └── style.css       # 所有样式
├── js/
│   ├── app.js          # 核心交互逻辑（按钮绑定、状态更新、动画触发）
│   ├── storage.js      # 数据持久化（localStorage读写、存档管理）
│   └── gameLogic.js    # 算法与规则（等级成长、经验计算、倒计时逻辑）
├── assets/
│   ├── images/         # 宠物图片/表情包
│   └── sounds/         # （可选）音效文件
└── docs/
    └── prompt.md       # 共享需求文档
```

## 宠物属性
- **饱食度** (hunger)：0-100，随时间下降
- **快乐度** (happiness)：0-100，随时间下降
- **精力** (energy)：0-100，随时间下降
- **清洁度** (hygiene)：0-100，随时间下降
- **健康值** (health)：0-100，由其它属性间接影响

## 交互操作
| 操作 | 主要效果 | 副作用 |
|------|----------|--------|
| 喂食 | +饱食度 | +快乐，+精力 |
| 玩耍 | +快乐度 | -精力，-饱食 |
| 睡觉 | +精力 (切换睡眠状态) | +快乐，-饱食 |
| 洗澡 | +清洁度 | +快乐，-精力 |
| 治疗 | +健康值 | -快乐，-精力 |

## 核心规则
- 每 5 分钟触发一次属性衰减
- 属性低于 30 会降低健康值
- 健康值归零时宠物重置
- 离线期间会累计衰减（最多 24 小时）
- 每次操作获得经验值，经验满升级

## 存档
- 自动保存：每次操作后
- 手动保存/读档/重置按钮
- 页面关闭时自动保存
- 启动时检测离线时间并计算
